## Pattern-piece name format
`<piece>, <sub-part> <n> — <side>` e.g. *Skirt Tier 2 Left Back* → «Спідниця, ярус 2 — зліва ззаду».
Sides: Front → спереду, Back → ззаду, Left → зліва, Right → справа.

## Style tags

## Item names (fabrics, trims, bows, accessories)
Format: **«Тип, колір»** — e.g. *Ivory Double Ruffle Trim* → «Подвійна рюша, айворі», *Dusty Pink Big Bow* → «Великий бант, пудровий».
- Colour adjectives agree with the type (Рюша, сиза · Мереживо, сизе); colour nouns never change (айворі, бордо, гліцинія).
- Named designs keep short quotes: «Мереживо «Тіара», волошкове», «Шовк-омбре «Латаття»».
- No filler words: «кольору», «оздоблення з…», «з крихітними». Trim without another type → «Тасьма»; Gradient → омбре; Beaded → з бісером; Burnout velvet → Деворе; Broderie anglaise → Шитво.
- Silk/Velvet is left out of bow names (the icon shows the fabric). Two different items never share one name: `tools/check_widths.py` fails if they do, or if a name is wider than the widest English item name.
